# Coloration racks – vues Cadwork

Correctif : détection robuste des repères Cadwork quand le PDF découpe le texte en fragments.

## Utilisation
1. Remplacer `index.html` dans GitHub par celui-ci
2. Charger la vue PDF
3. Charger le colisage CSV/XLSX
4. Cliquer sur **Charger / colorer**
5. Exporter le PDF annoté
