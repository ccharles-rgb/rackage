# Coloration racks – vues Cadwork

Site statique à déposer sur GitHub Pages.

## Utilisation
1. Ouvrir `index.html`
2. Charger une vue axonométrique PDF vectorielle exportée depuis Cadwork
3. Charger un colisage CSV/XLSX ou coller un texte avec `Rack ; Repère`
4. Cliquer sur **Charger / colorer**
5. Exporter le PDF annoté

Version actuelle : coloration fiable des repères par rack. Étape suivante : mode murs remplis avec gabarit de contours.
